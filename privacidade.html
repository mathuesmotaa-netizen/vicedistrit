Política de Privacidade

Privacy Policy · Última atualização / Last updated: 21/11/2026

1. Dados usados · Data we use

Ao autorizar pelo TikTok Login Kit, a ferramenta recebe o identificador da conta (open_id), informações básicas do perfil (nome e foto), as opções de privacidade de postagem e os tokens de acesso. Também usa os arquivos de vídeo e as legendas escolhidos pelo dono.

When authorized via TikTok Login Kit, the tool receives the account identifier (open_id), basic profile info (name and avatar), posting privacy options and access tokens. It also uses the video files and captions selected by the owner.

2. Finalidade · Purpose

Esses dados são usados só para publicar os vídeos do dono na conta dele e confirmar o status da publicação.

This data is used only to publish the owner's videos to the owner's account and check the publishing status.

3. Armazenamento · Storage

Os tokens ficam salvos apenas no computador do dono. Não há servidor, banco de dados ou coleta de dados de outros usuários.

Tokens are stored only on the owner's computer. There is no server, database, or collection of other users' data.

4. Compartilhamento · Sharing

Nenhum dado é vendido ou compartilhado com terceiros. Os vídeos são enviados somente ao TikTok, pela API oficial.

No data is sold or shared with third parties. Videos are sent only to TikTok, through the official API.

5. Exclusão · Deletion

Para remover o acesso, revogue o app nas configurações do TikTok e apague o arquivo de token do computador. Pedidos podem ser feitos pelo contato abaixo.

To remove access, revoke the app in TikTok settings and delete the token file from the computer. Requests can be sent to the contact below.
